# AI Study Assistant ⚡

A high-performance, real-time streaming AI study assistant built with FastAPI, Tailwind CSS, and Google Gemini (`gemini-3.6-flash`). Designed to deliver instant token responses with custom knowledge injection for coursework and exam prep.

---

## 🌟 Features

* **Instant Streaming**: Asynchronous token streaming via FastAPI (`client.aio`) and non-buffering headers.
* **Custom Context Injection**: Directly imports study materials, syllabus guides, or notes from `knowledge.txt`.
* **Clean Dark-Mode UI**: Built with Tailwind CSS and Lucide Icons, complete with persistent chat state and session resetting.

---

## 🛠️ Tech Stack

* **Backend**: Python 3.12, FastAPI, Uvicorn, Pydantic
* **AI Engine**: Google GenAI SDK (`gemini-3.6-flash`)
* **Frontend**: JavaScript, Tailwind CSS, Lucide Icons
